# Solutions

**Try each ticket for at least 30–45 minutes before opening its solution.** On the job nobody hands you the answer, and the struggle is the training.

Every fix here was tested against the lab database. Each solution covers:
- **Root cause:** what was actually wrong.
- **How you'd find it:** the investigation path, which matters more than the fix.
- **Fix:** code or SQL.
- **Data fix:** when bad data already exists.
- **Customer reply:** plain language, no jargon, owns the problem.
- **KB note:** what you'd write for the team.
