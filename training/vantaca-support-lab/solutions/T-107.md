# T-107 solution · Collections list

```sql
SELECT
    u.UnitNumber,
    ISNULL(o.FirstName + N' ' + o.LastName, N'(no current owner - foreclosure)') AS CurrentOwner,
    o.Email,
    ISNULL(c.TotalCharged, 0) - ISNULL(p.TotalPaid, 0) AS BalanceOwed
FROM dbo.Units u
OUTER APPLY (SELECT SUM(Amount) AS TotalCharged FROM dbo.Charges
             WHERE UnitId = u.UnitId AND DueDate <= '2026-10-15') c
OUTER APPLY (SELECT SUM(Amount) AS TotalPaid FROM dbo.Payments
             WHERE UnitId = u.UnitId AND PaymentDate <= '2026-10-15') p
LEFT JOIN dbo.Owners o ON o.UnitId = u.UnitId AND o.IsCurrentOwner = 1
WHERE u.AssociationId = 1
  AND ISNULL(c.TotalCharged, 0) - ISNULL(p.TotalPaid, 0) > 500
ORDER BY BalanceOwed DESC, u.UnitNumber;
```

**What makes this correct:**
- Charges and payments are aggregated separately (no fan-out, from T-102).
- `ISNULL` handles units with no payments (from T-102).
- The current-owner filter is in the LEFT JOIN's ON clause, so 112 stays visible (from T-101).
- Both sums respect the "as of" date, so the report stays the same if run again later.
